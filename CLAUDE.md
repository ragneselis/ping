# Claude rules for Ping

- Always reply to the user in English.
- Work on the `main` branch only. Do not create other branches.
- Never commit API keys, `.env`, `.env.local` or any other env/secret file. Keys live only in `.env.local` (git-ignored).
- Check pages in the browser yourself and give the user the localhost URL (e.g. http://localhost:3000) instead of screenshots.

See README.md for the stack and the data pipeline.
